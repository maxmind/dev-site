The following GeoIP database releases will be delayed until Tuesday, September
23, 2025:

- GeoIP City database
- GeoIP Country database
- GeoIP Enterprise database
- GeoIP ISP database

The GeoIP Anonymous IP, GeoIP Anonymous Plus, GeoIP IP Risk, and the GeoLite ASN
databases will be released today as scheduled.
