The GeoIP Connection Type database is now updated every weekday, Monday through
Friday. We recommend automating GeoIP database updates so that you can be sure
that you always have the most accurate IP geolocation and IP intelligence data.

You can automate database updates with our GeoIP Update program or other
methods. You can also download databases directly through the account portal.

[Learn how to automate database updates in this knowledge base article.](https://support.maxmind.com/knowledge-base/articles/download-and-update-maxmind-databases#api-endpoints)
