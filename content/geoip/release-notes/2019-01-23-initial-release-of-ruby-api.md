We have added Ruby as a MaxMind Supported GeoIP2 API
([RubyGems](https://rubygems.org/gems/maxmind-db),
[GitHub](https://github.com/maxmind/MaxMind-DB-Reader-ruby)). It provides a Ruby
reader for the MaxMind DB Database Format (used by the GeoIP2 databases and our
free GeoLite2 databases).
