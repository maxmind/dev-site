Effective September 21, 2020 we will be flagging significantly more IP networks
used by data centers and businesses as `Corporate` in the
[GeoIP2 Connection Type database](https://www.maxmind.com/en/geoip-databases).
We expect the size of the MMDB file to increase by about 20% and the size of the
CSV file to increase by about 210%.
