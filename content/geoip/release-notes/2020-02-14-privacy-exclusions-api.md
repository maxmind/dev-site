We've released a [Privacy Exclusions API](/geoip/privacy-exclusions-api/). This
API allows you to retrieve a list of IP addresses associated with valid “Do Not
Sell” or opt-out of sale requests in accordance with the California Consumer
Privacy Act (CCPA). You may view this list, along with more information, in your
[account portal](https://www.maxmind.com/en/accounts/current/do-not-sell-requests).
