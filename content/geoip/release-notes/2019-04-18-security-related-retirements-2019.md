In order to ensure your data is as safe and secure as possible, we will be
retiring support for TLS v1.0 and 1.1, unencrypted HTTP requests to our legacy
minFraud services, and our legacy minFraud SOAP API in the coming months. Please
see our
[blog](https://blog.maxmind.com/important-updates-about-tls-v1-0-v1-1-unencrypted-http-requests-and-the-legacy-minfraud-soap-api/)
for more info.
