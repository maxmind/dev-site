The `metro_code` data in our GeoIP products and services is a
no-longer-maintained code. Because Google does not use or publish these codes
any longer, the `metro_code` field has now been deprecated in our GeoIP products
and services.

**What should I do?**

The field will not be removed from our databases and existing values will
continue to be populated, so you can continue using it if you find it valuable.
