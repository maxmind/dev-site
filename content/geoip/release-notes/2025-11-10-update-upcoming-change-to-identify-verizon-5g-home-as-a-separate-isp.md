As
[previously announced](/geoip/release-notes/2025-11-03-upcoming-change-to-identify-verizon-5g-home-as-a-separate-isp/),
tomorrow, November 11, 2025, some networks previously labeled `Verizon Wireless`
will have their ISP name updated to `Verizon 5G Home` to improve coverage and
accuracy.

In addition, we will also be shortening the ISP name for
`Verizon 5g Home Internet` to `Verizon 5G Home`.

This change will be reflected in the following products and services:

- GeoIP ISP database
- GeoIP Enterprise database
- GeoIP City Plus web service
- GeoIP Insights web service
- minFraud Factors web service
- minFraud Insights web service
