Effective December 16, 2019, we will return `1` as the last digit for all 7
digit postal codes in Japan. The last digit refers to
[street-level resolution](https://en.wikipedia.org/wiki/Postal_codes_in_Japan)
and should not be relied upon for IP geolocation.
