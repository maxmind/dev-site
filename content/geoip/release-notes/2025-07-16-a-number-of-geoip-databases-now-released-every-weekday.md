The following GeoIP databases are now updated every weekday, Monday through
Friday:

- GeoIP City
- GeoIP Country
- GeoIP Enterprise
- GeoIP ISP

We recommend automating GeoIP database updates so that you can be sure that you
always have the most accurate IP geolocation and IP intelligence data.

You can automate database updates with our GeoIP Update program or other
methods. You can also download databases directly through the account portal.

[Learn how to automate database updates in this knowledge base article.](https://support.maxmind.com/knowledge-base/articles/download-and-update-maxmind-databases#api-endpoints)

The GeoIP Anonymous and Anonymous Plus databases will continue to update daily.
The GeoIP Connection Type and GeoIP Domain Name databases and all GeoLite
databases (except GeoLite ASN) will continue to update only on Tuesdays and
Fridays.
