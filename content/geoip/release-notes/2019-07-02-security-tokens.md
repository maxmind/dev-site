We've updated the direct download URLs for GeoIP databases in your account
portal to use security tokens instead of license keys. If you are a new user and
wish to use your own script or program to automate GeoIP downloads instead of
using our
[GeoIP Update Program](https://github.com/maxmind/geoipupdate/releases), there
are additional [steps to take](/geoip/updating-databases) after copying the
direct download URL from your account portal.

If you are an existing user that has already set up your own script or program
to automate GeoIP downloads, this change should not affect you, unless you add
new databases to your script or program. Instructions on additional steps are
[here](/geoip/updating-databases).
