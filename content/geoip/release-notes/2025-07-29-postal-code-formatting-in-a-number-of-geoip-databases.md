Yesterday, July 28, 2025, we released a number of GeoIP databases containing a
number of poorly formatted or incorrect postal codes. The impacted databases
were:

- GeoIP City
- GeoIP Enterprise
- GeoLite City

For a brief period of time yesterday, GeoIP web service users may also have
experienced web service responses in which these poorly formatted or incorrect
postal codes were returned.

This issue has now been corrected. Please ensure you have downloaded the latest
database release if you do not have automated database downloads set up. Web
service customers do not need to take any action to receive the corrected data.
