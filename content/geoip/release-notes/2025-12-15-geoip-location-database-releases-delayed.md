Due to an issue we are currently investigating, the GeoIP database updates for
Monday, December 15, 2025 for the following databases won't be released as
scheduled:

- GeoIP City database
- GeoIP Country database
- GeoIP Enterprise database
- GeoLite City database
- GeoLite Country database

The GeoIP Anonymous IP, GeoIP Anonymous Plus, GeoIP IP Risk, GeoIP ISP, and the
GeoLite ASN databases will be released today as scheduled.
