You can now download the GeoNames monthly diff report from the
[Download files](https://www.maxmind.com/en/accounts/current/geoip/downloads)
section of your account portal (direct link, log in required). The report is
available alongside your database downloads and can be downloaded automatically.
You can also download the report manually.

For download best practices, including how to automate downloads using a license
key, please
[review our documentation on the Dev Portal](/geoip/track-location-name-updates/).

As a result of this update, we will no longer be posting monthly diff report
release notes.
