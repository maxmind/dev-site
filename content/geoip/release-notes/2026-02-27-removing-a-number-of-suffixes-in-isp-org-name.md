We are removing suffixes (e.g. AB, A/S, Co, Corp, eood, Pte, Pvt, S. de R.L. and
others) and the LLC prefix from ISP/org names to match their current naming and
branding conventions.

**What should I do?** If you have rules or lists that require updating, ensure
that you match on ISP/org names that no longer have these suffixes or prefix.

You can
[download the list of ISP/orgs that will be changing](/csv/suffix-removal-in-ISP-or-org-name.csv).

We expect to release these changes in new database updates and web service
requests beginning Tuesday, March 10, 2026.

These changes will be reflected in the following products and services:

- GeoIP Insights web service
- GeoIP City Plus web service
- GeoIP ISP database
- GeoIP Enterprise database
