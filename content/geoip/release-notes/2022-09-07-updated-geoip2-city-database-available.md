We have released an updated version of the GeoIP2 City database, which fixes a
geolocation bug affecting some IPv6 addresses.

See the release note
[below](/geoip/release-notes/2022-09-07-geolocation-coordinate-bug-fix/) for
more information about this bug.

Customers should download the updated GeoIP2 City database at their earliest
convenience.
