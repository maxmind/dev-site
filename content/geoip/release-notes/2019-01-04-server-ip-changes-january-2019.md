On Monday, January 7, 2019 at approximately 15:00 UTC (10:00am EST), we will be
switching to static server IP addresses for traffic to our website and to
downloads.maxmind.com (used for GeoIP database downloads). The IP for the
hostname used by our web services or geoipupdate tool won't change immediately,
but if you whitelist IPs for any of our services we encourage you to add the new
IP addresses to your whitelist. The static IP addresses will be a subset of what
we list on our
[MaxMind server IP addresses page](/maxmind-server-ip-addresses/). We will
update the list of IP addresses on that page following the change. Please sign
up for the email list on that page if you want a notification when our server IP
addresses change.
