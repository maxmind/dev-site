GeoIP2 web service customers can now access
[anonymous IP data](https://www.maxmind.com/en/geoip-anonymous-ip-database)
through the
[GeoIP2 online lookup form](https://www.maxmind.com/en/accounts/current/geoip/lookup)
\[login required\] in the account portal. Select the
[GeoIP2 Insights web service](https://www.maxmind.com/en/geoip-api-web-services)
on the form when querying IP(s).
